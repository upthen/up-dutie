# ADR-0002 · 阅读器形态：句读式翻页书

日期：2026-09-28 ｜ 状态：**已由 v2 设计稿定稿**（见文末"v2 修订"）；本文件上半部分为 D 稿原型阶段的定型记录

## 决策（D 稿阶段）

阅读器采用**书本翻页式**，基本单元为**句对**：

- 一句原文 + 紧跟一句释义 = 一个句对；若干句对（约 4–8）构成一页；
- 原文繁体竖排从右起（楷体 ≥28px），释义简体小字紧贴其列旁（宋体 ≥17px），两者间一道细朱线；
- 版式语言取法古籍：宣纸底、乌丝栏界格、文武双栏版框、朱砂唯一强调色；
- 翻页向左（竖排书习惯）：页角点击 / 方向键 / 滚轮 / 按钮 + 汉字页码、`#pN` 深链；
- 繁/简（只切原文）、竖/横、字号 A－/A＋ 切换后**自动重新分页**（测量式贪心装箱）。

## 红线（历轮原型反馈的教训，实现不得突破）

1. 文字必须在界格内——界格逐原文块绘制、周期=列宽，禁止整页统一铺网格；
2. 界格只画到文字实际高度，禁止无字空格子；
3. 阅读区占视口宽 ≥2/3、高 ≥3/4，chrome 最薄；
4. 禁止横向卷轴、禁止"整块原文+整块释义"分区、禁止整段夹注（必须是句级对应）；
5. 界面无大圆角/渐变/投影卡片（反 SaaS）。

> 注：红线 2 与红线 4 中"禁止横向卷轴"已被 v2 修订（见下），其余依然有效。

## v2 修订（2026-09-28，外部设计稿定稿，存于 designs/v2/）

1. **线装升级为对开**：两叶一开、中缝版心书口（鱼尾、书名、段次、叶码）、3D 翻页动效。
2. **卷轴模式复活并与线装共存**：同一阅读页顶栏切换（?mode=book|scroll + localStorage 记忆）。原"禁止横向卷轴"调整为"卷轴仅为可选模式，线装为默认"。
3. **字级装箱取代句对块测量**：每字一格固定入栏（列宽=界行宽），空余栏位以隐藏槽位补齐——即古籍"界格通栏、字不满格留白"的原貌。原红线 2 的"界格只画到文字高度"由"槽位补格"方案取代，效果等价（不出现残缺半格）。
4. **翻页方向**：右角=后一开（→），页码为"开/叶"双计。
5. 环境底色黑白灰（#1A1A1A），书叶暖纸，对比增强。

## 被否决的备选（原型 A/B/C，已被清理未入库）

- **A 碑林·夹注式长卷**：整段双行夹注 + 横向卷轴——段级粒度打断阅读、卷轴交互被否；
- **B 观经·分段展陈**：段独立成节、竖排横滚——仍非书本，粒度仍为段；
- **C 案头·暗色同屏对照**：原文/释义双栏联动——"对应"成立但非书页形态，留作桌面端可选形态。
