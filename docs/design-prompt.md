# 「读帖」碑帖深读应用 · 设计稿 Prompt

> 用途：交给 AI 设计工具 / 设计师出高保真设计稿。直接全文粘贴即可，六、七两节的样例数据请保留，让稿子里是真实内容而非占位文。

## 一、项目背景

为一款**自用为主的书法学习网站**出设计稿。产品收录中国书法名碑帖的**原文与白话释义**，核心场景是"临池读帖"：练字前中后打开某本碑帖深读——**一句原文，跟一句释义，逐页而读**。产品气质定位是"数字化的古籍集注本"：释不离经、文人书卷气。

首篇内容（设计稿请用它做真实内容）：
**《集王圣教序》**——唐·咸亨三年（672）刻；太宗文皇帝李世民撰文；弘福寺沙门怀仁集晋右将军王羲之书；行书；原石今存西安碑林博物馆。正文《大唐三藏圣教序》共四段、约四十余句，见第六节样例。

## 二、已确定的产品形态（不要偏离）

经过多轮迭代，以下形态已经拍板，设计不要另起炉灶：

1. **书本翻页式阅读器**：固定书页、翻页交互。**不是**长页滚动，**更不是**横向卷轴。
2. **"句对"是基本内容单元**：一句原文 + 紧跟的一句释义 = 一个句对；一页排若干句对（约 4–8 组，视字号与窗口）。
3. **原文繁体、竖排、从右起**；**释义简体、小字、紧贴在该句原文的左侧**（同一视觉组内，读原文余光即释义）。
4. **版式语言取法古籍**：宣纸底色、乌丝栏界格（竖向细线格）、文武双栏版框（外粗内细两圈边线）、朱砂色点缀。
5. **翻页方向遵循竖排书习惯：向左翻**（书页左角 = 后一页，右角 = 前一页）。

## 三、硬性要求（历轮反馈的教训，逐条必须满足）

1. **文字必须在界格内**：界格线与文字列必须严格对齐。实现上界格必须"跟着每个原文块自己画"（每个原文块的列宽 = 格宽周期），**禁止**整页统一铺一张网格背景——那样句块起点不一，文字必然骑线。
2. **不许出现空格子**：界格只画到该句文字的实际高度为止，字没写到的地方不画格。满页无字的空界格会像"半成品表格"。
3. **阅读区要大**：书页占视口宽度 ≥ 2/3、高度 ≥ 3/4；顶栏、页码条等 chrome 压到最薄。宁可功能少，不可书页小。
4. **字号硬指标**：原文大字 ≥ 28px（楷体），释义 ≥ 17px（宋体），并提供字号调节。
5. **禁止两种已被否决的结构**：a) 全部原文一块 + 全部释义一块的前后分区；b) 一整段原文后跟一整段释义的夹注式。必须是**句级**对应。
6. 原文与释义之间要有**清晰而克制**的分隔：一道细朱线（约 1.5px，朱砂色 45% 不透明度）。
7. 界格线可见但不抢：棕色、约 45% 不透明度，不能淡到融进纸色。
8. 页尾允许参差留白（最后一句对之后到页边的空白）——这是古籍常态，可接受；若要更整齐，可做"每页固定列数、句对均匀分布"的备选方案一起出。
9. **避免 SaaS 感**：不要大圆角卡片、彩色投影、渐变按钮、Notion 式布局。克制、留白、纸墨感。

## 四、页面清单（需出稿的页面）

1. **碑帖列表页（首页）**：按朝代/书体分组的碑帖条目（碑名、朝代、书者、书体），含"计划中"的未收录条目（灰置）。
2. **条目扉页**：竖排大字碑名 + 展签式元信息（朝代/撰文/集书/原石）。
3. **阅读页（核心页面，重点出稿）**：书页式句对排版，含翻页 hover 态（页角浮出朱底提示块）、页码态。
4. **跋页**：校记（异文与碑刻用字说明，如"涂间失地"之"涂"通"途"）+ 朱字"终"收尾。

## 五、交互规格

- **翻页**：点击书页左右两角（hover 出提示）、方向键（← 后页 / → 前页）、滚轮、底部按钮组 + 汉字页码（如"五／十"）。
- **繁/简切换**：只切换原文，释义恒为简体。
- **竖/横切换**：竖排版 ↔ 横排版。横排时句对变为"原文一行 + 缩进释义一行"上下相邻。
- **字号 A－/A＋** 与窗口尺寸变化后**自动重新分页**。
- 顶栏常驻：印章式站标、段跳转（段一～段四）、繁简/竖横切换、字号按钮。
- 桌面优先（约 1920×980 为主力视口），窄屏时书页单列自适应。

**句对样例数据**（真实内容，设计稿直接使用；格式：段号｜原文（繁）｜释义）：

- 一｜蓋聞二儀有像，顯覆載以含生；四時無形，潛寒暑以化物。｜听说天地两仪有其形象，凭借天覆地载而容纳生灵；四季没有形体，却在不知不觉中以寒来暑往化育万物。
- 一｜是以窺天鑑地，庸愚皆識其端；明陰洞陽，賢哲罕窮其數。｜所以仰观天文、俯察地理，再平庸愚钝的人也能认识其端倪；而要洞彻阴阳变化的奥妙，即使贤人哲士也很少能穷尽其数。
- 三｜松風水月，未足比其清華；仙露明珠，詎能方其朗潤。｜松间清风、水中明月，不足以比拟他的清朗光华；仙人甘露、皎洁明珠，又怎能比拟他的明朗温润？
- 三｜萬里山川，撥煙霞而進影；百重寒暑，躡霜雨而前蹤。｜万里山川，拨开烟霞映日前行；百重寒暑，踏着霜雨继续前踪。
- 四｜譬夫桂生高嶺，雲露方得泫其華；蓮出淥波，飛塵不能汙其葉。｜譬如桂树生在高岭，云露才能滋润它的花；莲花出于清波，飞尘无法玷污它的叶。
