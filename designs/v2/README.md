## ⚠ 内容警告：pairs-data.js 的文案是设计占位，不是核对原文

`pairs-data.js` 中**混有大量不属于《大唐三藏圣教序》原文的句子**，包括：

- 「若夫水懷珠而川媚，石蘊玉而山輝」——出自陆机《文赋》；
- 「是以名無翼而長飛，道無根而永固」——近似《述圣记》（高宗记）文句；
- 「升則雲布法雨於六合」「方域之中無思不服」「朝遊崑崙之嶺，夕憩於星河之濱」「愛日遄居，閱川長往」等——疑似 AI 生造或他文拼凑，**均不见于圣教序碑文**；
- 段号也有错位（如「松風水月」句标为段三是对的，但「況乎佛道崇虛」实际属段一末）。

**正式实现的内容一律以 `content/sheng-jiao-xu.json`（已核对 47 句对）为准**，不得使用本目录的 pairs-data.js 文案。设计稿自带的跋页也注明了"設計稿僅錄部分句對作版式示範"。

## v2 相对 D 稿原型的形态变化（供实现注意）

1. **线装升级为对开（两叶一开）+ 版心书口**：鱼尾、书名、段次、叶码居中缝；3D 翻页动效（rotateY 165°）。
2. **卷轴模式复活**：与线装同页共存、顶栏切换（?mode= + localStorage 记忆）；卷轴为裱绢横展手卷。
3. **字级装箱**：每字一格固定入栏（列宽 = 界行宽），从结构上保证入格；空余栏位以隐藏槽位补齐界格——即"界格通栏、字不满格留白"的古籍原貌，与 D 稿"界格只画到文字高度"不同，**以 v2 为准**。
4. **翻页方向**：右角=后一开（→），横排模式下句对为"原文行+行内小字释义"。
5. 环境底色改为黑白灰（#1A1A1A），书叶保持暖纸，对比更强。
